1. Book Library Management






















5














This is one of ReadEra's biggest strengths.
1.1 Automatic book detection
- Automatically scans the device for supported ebook and document files.
- Detects downloaded books.
- Detects PDF documents and articles.
- Detects ebooks stored in different folders.
- Adds detected books to the library.
- Avoids requiring users to manually register every book.
- Allows quick access to discovered files.
For example, when a user downloads an EPUB file into their Downloads folder, ReadEra can detect it and display it in the library.
1.2 Book library
- Displays detected books and documents.
- Displays book covers.
- Displays book titles.
- Displays author information.
- Displays document information.
- Supports large libraries.
- Provides access to recently read books.
- Provides navigation between different library categories.
ReadEra reports testing its library with more than 500,000 books and documents.
1.3 Reading lists
ReadEra provides three built-in reading lists:
- To Read: Books that the user intends to read.
- Have Read: Books the user has finished.
- Favorites: Books the user particularly likes.
These lists make it easier to separate books based on reading intentions and status.

An important distinction for Reading Sanctuary: ReadEra's TTS functionality is not the same as a full audiobook management system.

Its official feature descriptions focus on converting text-based books and documents into speech. They do not establish a complete audiobook folder scanner, chapter-based MP3/M4B library, or audiobook import system comparable to dedicated audiobook players.
