# Reading Sanctuary (Flutter) - Milestone 1: Foundation

## Run
```
flutter create . --platforms=android,ios,web   # generates platform folders, keeps lib/
flutter pub get
flutter analyze && flutter test
flutter run -d chrome
```
## Included in Milestone 1
Theme system (Dark Academia + Warm Parchment), GoRouter shell, responsive navigation
(bottom bar / collapsible sidebar), mock repository, Home, Library (search + status filters),
Book Details (status changes). Every other route is a labelled placeholder for its milestone.
